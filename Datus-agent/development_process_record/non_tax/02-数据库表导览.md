数据库 `yunnan0508` 中共有 **480+ 个表**（含视图），看起来是一套**财政非税收入收缴管理系统**。按业务域分组如下：

## 📊 收入统计与汇总（fne_stats_ / tax_）
| 表                                                        | 说明                     |
| --------------------------------------------------------- | ------------------------ |
| `fne_stats_income` / `_month` / `_year` / `_bak` / `_tmp` | 非税收入统计（日/月/年） |
| `fne_stats_income_agen_month` / `_produce`                | 按执收单位的月度收入统计 |
| `fne_stats_budget_year`                                   | 预算年度统计             |
| `fne_income_daybook`                                      | 收入日记账               |
| `fne_stats_income_mv`                                     | 物化视图                 |
| `tax_stats_income_month`                                  | 税收收入月度统计         |

## 🧾 缴款书核心（une_）
| 表                                                           | 说明                                                      |
| ------------------------------------------------------------ | --------------------------------------------------------- |
| `une_cbill_new` / `_item_new` / `_medical` / `_high`         | 缴款书主表 / 明细 / 医疗 / 高频                           |
| `une_mid_cbill_day`                                          | 缴款书日中间表                                            |
| `une_paybook_new` / `une_paybook_high` / `une_paybook_agg`   | 缴款簿（新/高频/聚合）                                    |
| `une_writeoff_new`                                           | 核销记录                                                  |
| `une_paybook_linkquery`                                      | 缴款簿关联查询                                            |
| `une_paybook_new_2021~2027_530xxx` / `une_paybook_high_2021~2027_530xxx` | **按年份+行政区划的分表**（530000=云南省，5301xx=州市等） |

## 🏢 基础档案（fab_）
`fab_agen`（执收单位）、`fab_item`（收费项目）、`fab_subject`（科目）、`fab_dept`、`fab_place`、`fab_acc`（账户）、`fab_bill` / `fab_billbatch`（票据）、`fab_treasury_acc`（财政专户）、`fab_item_std`、`fab_item_tag` 等

## 📦 票据库存管理（ube_ / fbe_ / ubr_）
- **入库**：`ube_stock_in`、`ube_stock_prtplan`（印制计划）、`ube_stock_return`（退回）、`ube_stock_invalid`（作废）
- **出库**：`fbe_stock_out`、`fbe_writeoff`（核销）、`fbe_writeoff_billitem`
- **库存**：`ubr_stock`

## 💰 资金归集与划转（fne_）
`fne_backpay`（退付）、`fne_funddivide_new`（资金分成）、`fne_transfer_new`、`fne_treasury_transfer_new`（专户划转）、`fne_agen_treasury_high/new`

## 🏛️ 组织与权限（afa_ / uaa_ / uab_）
`afa_org`（机构）、`afa_user`（用户）、`afa_auth_region`（区域权限）、`afa_res_dict`（字典）、`uab_place`（地区）、`uab_place_user`

## 🏥 医疗与税务相关
`ibb_basic_medicalorg`（医疗机构）、`mv_medicalorg_agen`（视图）、`tips_tax_bill_wide`（税务票据宽表）、`cs_fcreditcode`（统一社会信用代码）

## ⚙️ 监管、支付与工具
- **监管**：`mon_billtype`、`mon_industry_agen`、`mon_major_project`、`mon_subject_type`
- **支付**：`ps_transacccache`（交易账户缓存）、`fpf_bank`、`fpf_clear_transfer`（清算划转）
- **规则**：`FAB_RULE*` 系列
- **电子发票**：`eieinvoicedata`、`eiinvoiceitems`
- **ETL/工具**：`etl_sync_log`、`etl_writeoff_count`、`table_columns_clickhouse`、`tool_monitor_item_*`
