# 资金链与票据链宽表选型清单（智能问数用）

> **定位**：智能问数（自然语言 → SQL）的选表依据。按业务场景列出"宽表首选 + 底表备用 + 已验证关联键 + 口径坑"。
>
> - 场景依据：[01-非税业务说明](01-非税业务说明.md)，分**资金链**（钱：缴款人 → 国库）与**票据链**（票：开票 → 作废/冲红 → 核销）两条线。
> - 数据源：`yunnan0508`（ClickHouse）；行数与关联键均为 2026-10-17 实测验证（system.tables / system.columns / JOIN 对账）。
> - 配套：[02-数据库表导览](02-数据库表导览.md)（全库表分组导览）。

## 〇、总原则（粒度与键）

1. **粒度**：`_high` 宽表中 **`fid` = 明细行 ID**、**`fpid` = 主单 ID**。`_new` 主表的 `fid` 是主单 ID——与宽表的 `fid` 不是同一个东西，跨表连 `fid` 会静默得到 0 行。
2. **对账证据**：`fne_paybook_full_high.fimamt` 合计 = `fne_funddivide_transfer.fimamt` 合计 = **16,016,079,467.68**（分毫不差），证明宽表就是底表链 JOIN 的预物化。
3. **票据↔缴款唯一连通键 = `fpaycode`**：用 `fpid` / `fbillid` 跨链直连实测均为 0 行。
4. **默认走宽表，底表仅当宽表缺列时降级使用。**

## 四、选表规则（问数引擎口径）

1. **默认走宽表**：F1-F5 → `fne_paybook_full_high`；F6 → `fne_treasury_transfer_new`；B1/B2 → `une_cbill_high` / `une_paybook_high`；**只有底表缺列时才降级底表链**。
2. **金额 SUM、笔数 `uniqExact(fid)`**：`full_high` 有 147 个重复 `fid`（生命周期多版本行），多版本行不带金额，故金额可直 SUM、笔数必须去重。
3. **票据关联只用 `fpaycode`**，禁用 `fpid` 跨链直连。
4. **空键过滤**：任何 `fcollectid / fpaybooksubid != ''` 前置（funddivide 有 178 行空 `fcollectid`，不过滤产生 2 万+ 行假关联）。
5. **汇缴（une_）与直缴（fne_）严格分口径**，不得 UNION 求总收入（业务篇口径提示 1：缴款人定义两表不同）。
6. **忽略分表**：`*_YYYY_530xxx`（2021~2027 × 各州市）全库合计 <1,400 行且几乎全空（仅 1 张非空），历史数据在 `_high` 主表中已覆盖（`_high` ⊇ `_new`，且起点更早：cbill_high 从 2019-08、paybook_high 从 2021-06 起）。
7. **`_high` ≠ `_new` 增量关系**：`une_paybook_high.fpid` = `une_paybook_new.fid`（7,407 命中）、`une_cbill_high.fpid` = `une_cbill_new.fid`（47,486 命中），但按 `fid` 直接比对交集为 0——**键语义不同，勿混用**。

## 五、参考 SQL 骨架（ClickHouse）

```sql
-- F2/F3/F4：收入+清分+归属，一张宽表搞定，无需 JOIN
SELECT fchgbgtagenname AS 执收单位, fsubname AS 科目,
       sum(famt)      AS 缴款金额,
       sum(fimamt)    AS 清分金额,
       uniqExact(fid) AS 明细笔数,          -- 笔数必须去重！
       frecrgnname    AS 归属区划,
       fcollectid     AS 汇总批次
FROM yunnan0508.fne_paybook_full_high
WHERE fcleardate >= '2024-01-01'
GROUP BY 1,2,6,7;

-- F6：缴库批次（ftransdate 空时用 fmsgdate 兜底）
SELECT tt.*, fdt.fchgbgtagenname
FROM yunnan0508.fne_treasury_transfer_new tt
LEFT JOIN yunnan0508.fne_funddivide_transfer fdt
       ON tt.ftranscollectid = fdt.fcollectid
WHERE tt.ftranscollectid != '';

-- B3/B4：票据↔缴款（唯一连通键 fpaycode）
SELECT c.*, u.fagenname
FROM yunnan0508.une_cbill_high c
LEFT JOIN yunnan0508.une_paybook_high u
       ON c.fpaycode = u.fpaycode;
```
